## 二、目录约定

```
data/    # 切分与检索的输入，NN_ 前缀 + YAML front-matter + Markdown 正文
raw/     # 原始 PDF 快照，每份 data/*.md 都必须能在此找到对应原文
```

`data/*.md` 的 front-matter 字段（**必填**）：

| 字段 | 含义 | 用途 |
|---|---|---|
| `id` | 文档唯一标识 | 跨文件引用 |
| `title` | 文件正式名称 | 人工核对 |
| `doc_no` | 文号 | 引用出处 |
| `issuer` | 发布机关 | 权威性判断 |
| `issued_date` / `effective_date` / `expire_date` | 发布/生效/失效日期 | **时效过滤**，解决 2020 版 vs 2025 版冲突 |
| `source_url` | 原文链接 | 溯源 |
| `raw_snapshot` | `raw/` 下的 PDF 文件名 | 快照校验 |
| `status` | `effective` / `superseded` / `draft` | 版本消歧 |

## 三、收录原则

1. 只收 `.gov.cn` / `.sh.cn` 域名的原文；无原文佐证的二手信息一律不进库。
2. 每份文件必须保留 PDF 快照于 `raw/`，文件名与 front-matter 的 `raw_snapshot` 一致。
3. 正文照抄，不改写、不归纳；抄录疑点写进 front-matter 的 `notes`。

## 四、已知缺陷分类（bad case 种子）

| 类型 | 例子 | 当前处理 | 计划解法 |
|---|---|---|---|
| 悬空引用 | "详见本市紧缺急需人才目录" | prompt 要求缺依据即拒答 | 跨文档关联 / 明确拒答 |
| 时效冲突 | 2020版 vs 2025版 | front-matter 已含 `status`/`effective_date`，**尚未接进检索过滤** | 按 `effective_date` 过滤召回 |
| 数值年度变动 | 社保基数倍数、提取限额 | 无 | 独立成条 + 年份元数据 |
| 主体错位 | 个人 vs 用人单位申报 | 查询改写规则补充"用人单位" | prompt 前提校验 |
| 多条件合取 | 学历+院校排名+社保时长 | 邻条上下文窗口 `context_window=1` | 跨 chunk 组装 |

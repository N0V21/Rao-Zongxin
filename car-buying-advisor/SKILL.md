# 全渠道购车对比报告

把用户的车型输入，变成一份**可核验**的渠道对比报告。这个 skill 的价值不在于"给个数"，而在于**把每个数字的来源、时间和置信度摆清楚**，让用户知道哪些能直接用、哪些必须打电话或到店确认。

---

## 0. 三条铁律（先读，违反即失败）

1. **绝不编造**电话号码、门店名、地址、车源编号、价格、公里数、事故记录。只引用检索结果里**真实出现**的信息，并附来源链接。
2. **绝不把"官方指导价"或"平台挂牌价"说成"成交价"**。没有来源的成交价，一律写"未获取"。
3. **事故/出险/维保/调表记录属于付费或实名数据**，公开检索通常拿不到。拿不到就明确写"公开渠道无法获取"，并给出核验方法——**不许推测**。

用户要的是能拿去做决策的信息，一条编造的 400 电话比十条"未获取"的危害大得多。

---

## 1. 第一步：锁定口径（信息不全就先问）

从用户输入中提取，缺失且影响结果的关键项**先问再查**：

| 字段 | 为什么关键 | 缺失时 |
|---|---|---|
| 品牌 + 车系 | 检索的必要条件 | **必须问** |
| 年款 / 配置 | 价格能差几万到几十万 | 可先按在售年款检索，但报告里注明假设 |
| 城市 | 经销商、优惠、补贴、限迁都强地域相关 | **必须问**（二手车尤其） |
| 新车 / 二手车 / 都看 | 决定检索面 | 默认两者都给 |
| 预算 / 是否置换 | 影响补贴与贷款方案 | 可省略 |

用一次提问把缺的信息问全，不要来回问三轮。

**务必先确认的两个高频陷阱**：
- **「××款」≠「××年上牌」**。2018 款可以是 2018 年上牌，也可以是 2017 款在 2018 年上牌——年款与上牌年份是两件事，配置和价格都不同。
- **新车是否仍在售**。用户给的老年款往往早已停售，那就不存在新车渠道报价；声称有新车的一律可疑。

---

## 2. 第二步：并行检索（一轮发多条查询）

搜索工具通常每次接受 1–4 条查询，**把下面的模板成组并发**，不要串行。

### 新车组
- `{品牌} {车系} {年款} 官方指导价 配置表`
- `{城市} {品牌} {车系} 4S店 报价 优惠 落地价`
- `{品牌} {车系} 官方 门店查询 经销商 地址 电话`
- `{品牌} {车系} 车主成交价 落地价 {城市}`
- `{品牌} {车系} 汽贸 二级经销商 报价`
- `京东汽车 / 天猫汽车 {品牌} {车系} 优惠 交付`

### 二手车组
- `{品牌} {车系} {年款} 二手车 价格 {城市}`
- `瓜子二手车 {车系} 报价 公里数`
- `懂车帝二手车 {车系} {城市} 车源`
- `{车系} 三年保值率 二手车行情`
- `{车系} 常见故障 通病 事故 召回`

### 政策组（影响落地价，别漏）
- `{城市} 汽车以旧换新 补贴 2026 细则`
- `{车系} 新能源 购置税 2026 减半`
- `{城市} 二手车 迁入 排放标准 国六`

### 渠道与车况核验组
- 品牌官网 / 官方 App 的"经销商查询"页 → **联系方式的一级来源**
- 平台车源详情页 → 公里数、上牌时间、过户次数、检测报告摘要

> 各渠道清单、风险特征、验车与合同要点见 `references/channel-guide.md`。
> 证据分级细则、落地价公式与补贴口径见 `references/evidence-grading.md`。
> 报告骨架见 `assets/report-template.md`。
> 完整的真实产出样例见 `examples/mercedes-e-coupe-2018-shanghai.md`。

**二手车务必检索车源档案页**（而不只是挂牌列表页）。档案页通常给出出厂日期、首次上牌日期、排放标准、使用性质、VIN 前段、检测报告入口——这些是挂牌列表没有的关键字段。

---

## 3. 第三步：证据分级（报告的骨架）

**每一条数据都必须带等级 + 来源链接 + 抓取日期。**

| 等级 | 含义 | 典型来源 |
|---|---|---|
| **A** | 官方口径 | 车企官网/官方 App/官方客服、政府网站（政策文件） |
| **B** | 平台公开挂牌 | 汽车之家、懂车帝、易车、瓜子的经销商报价或车源列表 |
| **C** | 第三方/自媒体 | 论坛车主成交价、测评、拍卖记录 |
| **D** | 未获取 | 只能电话/到店/付费查询确认的信息 |

规则：
- 同一数据点尽量**两个独立来源交叉验证**；冲突时两个都列，不要私自取平均。
- **发现来源本身有错时要标注出来**（例如把长轴距轿车混入轿跑价格区间），并据此下调该来源的证据等级。
- 报告结尾必须有 **"数据缺口与待人工确认项"** 一节，把 D 级信息集中列出，并写清**用什么动作补上**（打哪个电话、查哪个平台、看哪份材料）。

详细判定标准、置信度降级规则见 `references/evidence-grading.md`。

---

## 4. 第四步：落地价计算（别只报裸车价）

各渠道最终要能横向比，统一折算成**落地价**：

```
落地价 = 裸车价 + 购置税 + 保险 + 上牌费 + 服务费 − 可享补贴
```

- **燃油车购置税** ≈ 裸车价 ÷ 1.13 × 10%
- **新能源购置税**：2026-01-01 至 2027-12-31 **减半征收（按 5%）**，每辆新能源乘用车减税额不超过 **1.5 万元**（2024–2025 年是免征、每辆免税额不超过 3 万元，**已过期，别用旧口径**）
- **2026 年以旧换新补贴**（《2026 年汽车以旧换新补贴实施细则》，商办消费函 2025 年第 467 号）：
  - 报废更新：买新能源按售价 **12%**、最高 **2 万**；买 2.0L 及以下燃油按 **10%**、最高 **1.5 万**
  - 置换更新：买新能源按售价 **8%**、最高 **1.5 万**；买燃油按 **6%**、最高 **1.3 万**
  - 前置条件：旧车须 **2025-01-08 前**登记在本人名下；票据日期须在 2026-01-01 之后；**每人只能享受一次**；发票与登记须在**同一省级地区**
- **二手车另有三项常被忽略的成本**，必须单独列出：
  1. **牌照额度**（如上海、北京需新增额度，可能**与车价同量级**）
  2. **整备预算**（8 年车龄建议预留 1–2 万：轮胎、大保养、刹车片、油液）
  3. **过户费与服务费**
- 新能源车还要提醒：**三电终身质保常仅限首任车主**，买二手前必须向官方书面确认质保是否随车转移。

---

## 5. 第五步：输出对比报告

按 `assets/report-template.md` 的骨架写入
`购车对比报告_{车型}_{城市}_{YYYY-MM-DD}.md`，然后用交付工具（如 present）把文件交给用户。

八节结构：结论先行 → 价格总览 → 渠道明细 → 车况核验清单 → 避坑提示 → 结论与推荐路径 → 数据缺口与待确认项 → 信息来源。

**写作要求**
- 数字要能追溯到来源链接，做不到就标 D。
- 同一车型不同渠道价差大时，**解释原因**（授权 vs 串货、库存车、地区补贴差异），而不是只罗列。
- 用**残值率**（现价 ÷ 当年指导价）给用户一个判断报价是否离谱的基准线。
- 结尾明确写一句：本报告不构成购车决策建议，价格与车况请以线下核验和书面合同为准。

---

## 6. 常见失败模式（自查）

- 用户没给城市就开始报"全国最低价" → 价格强地域相关，**必须先问**。
- 把平台的"经销商报价"当成 4S 店承诺价 → 那通常是**引流价**，标注 B 级并提示"需电话确认是否有附加条件"。
- 二手车的公里数直接写成确定值 → 必须区分**卖家自述/表显**与**检测报告记载**。
- 给了电话却没来源 → 只有官网/官方客服/挂牌页公示的才能写，并且带链接。
- 用 2025 年的购置税免征口径算 2026 年落地价 → 已过期，见第 4 节。
- 忽略排放限迁就推荐异地车源 → 国五车进不了执行国六 b 的城市（如长三角），**先查迁入标准再谈价格**。
- 把平台标注的「欧5/欧6」当成中国的「国五/国六」 → 欧洲标准 ≠ 中国环保信息公开等级，必须按 VIN 另查。
- 报告只有结论没有缺口清单 → 必须写，这是本 skill 的核心交付物之一。

# GitHub Copilot 自定义指令 · 购车对比报告

当用户给出车型并询问价格、渠道、车源、车况（「多少钱」「落地多少」「哪个渠道买便宜」「二手车行情」「有没有事故」「值不值得买」）时，按下述规则产出对比报告。完整规则见仓库根目录 `SKILL.md`。

## 三条铁律

1. **绝不编造**电话号码、门店名、地址、车源编号、价格、公里数、事故记录。只引用检索结果里真实出现的信息，并附来源链接。
2. **绝不把"官方指导价"或"平台挂牌价"说成"成交价"**。没有来源的成交价一律标注"未获取"。
3. **出险/维保/调表记录属于付费实名数据**，公开检索拿不到时写"公开渠道无法获取"并给出核验方法，**不许推测**。

## 执行步骤

1. **锁定口径**：品牌+车系、年款/配置、城市、新车还是二手。缺关键项先一次性问全。
   - 「××款」≠「××年上牌」
   - 老年款新车通常早已停售，不存在新车渠道报价
2. **并行检索**：官方指导价、本地经销商报价、车主成交价、二手车车源、保值率、车型通病、以旧换新补贴、迁入排放标准。
3. **证据分级**：`A` 官方 / `B` 平台挂牌 / `C` 自媒体 / `D` 未获取，每条数据附来源链接与抓取时间。
4. **计算落地价**：`裸车价 + 购置税 + 保险 + 上牌费 + 服务费 − 可享补贴`
   - 燃油车购置税 ≈ 裸车价 ÷ 1.13 × 10%
   - 新能源 2026-01-01 至 2027-12-31 减半征收（5%），每辆减税额 ≤ 1.5 万元
   - 2026 年以旧换新补贴：报废更新买新能源最高 2 万、燃油最高 1.5 万；置换更新买新能源最高 1.5 万、燃油最高 1.3 万
   - 二手车须另列：牌照额度、整备预算、过户服务费
5. **输出报告**：八节结构（结论 / 价格总览 / 渠道明细 / 车况核验清单 / 避坑提示 / 推荐路径 / 数据缺口 / 信息来源），保存为 `购车对比报告_{车型}_{城市}_{日期}.md`。

## 必查项

- **排放限迁**：长三角、珠三角等重点区域只接受国六 b 迁入；国五车可能无法异地迁入。
- **欧标 ≠ 国标**：平台标注的「欧5/欧6」不等于中国的「国五/国六」，须按 VIN 查环保信息公开等级。
- **沪牌/京牌额度**：可能是一笔与车价同量级的成本。
- **融资租赁陷阱**：合同标题是《融资租赁合同》而非《贷款合同》时，还款期间车辆所有权不属于买家。

# 证据分级、落地价与补贴口径

本文件是 `SKILL.md` 第 3、4 节的展开细则。当报告需要更严格的标注标准，或需要向用户解释"为什么这个数字只能标 D"时读这里。

---

## 一、A/B/C/D 证据分级

### A 级 · 官方口径

可直接引用、可作为决策依据。

- 车企官网 / 官方 App 公布的指导价、配置表、门店查询结果
- 车企官方客服公示的电话与地址
- 政府网站：政策原文、补贴细则、车管所与生态环境部门规定
- 车辆法定证件：《机动车登记证书》《机动车行驶证》《机动车销售统一发票》《二手车销售统一发票》

**仍要注意**：官方"指导价"不是成交价；官网门店列表可能未及时更新。

### B 级 · 平台公开挂牌

可用作价格锚点，但**必须提示"挂牌价 ≠ 成交价"**。

- 汽车之家、懂车帝、易车、车300、瓜子等的经销商报价与车源列表
- 二手车交易市场平台的车源档案页
- 拍卖平台的成交记录

**降级触发条件**（出现任一条，该来源整体降为 C 级）：
- 平台本身是引流性质，报价明显低于行情且无细则
- 内容存在明显分类错误（如把长轴距轿车混入轿跑价格区间）
- 无法追溯到原始挂牌页，只有二手转载

### C 级 · 第三方 / 自媒体

只能作为**背景与交叉验证**，不能单独支撑结论。

- 车主论坛成交价、自媒体行情文章、测评
- 车商口述、行业传闻

### D 级 · 未获取

**这是最有价值的一类标注**——它明确告诉用户"还差什么"。

典型 D 级信息：
- 真实成交价（只有电话/到店才知）
- 出险记录、维保记录、真实里程（付费实名数据）
- 具体某台车的事故历史
- 当地过户费、服务费、保险的实际报价
- 牌照额度价格

**每条 D 级信息都必须配一个"怎么补"的动作**，否则标注没有意义。

## 二、落地价公式与口径

```
落地价 = 裸车价 + 购置税 + 保险 + 上牌费 + 服务费 − 可享补贴
```

### 购置税

| 车辆类型 | 口径 |
|---|---|
| 燃油车 | ≈ 裸车价 ÷ 1.13 × 10% |
| 新能源（2026-01-01 至 2027-12-31） | **减半征收，按 5%**，每辆新能源乘用车减税额 ≤ **1.5 万元** |
| 新能源（2024–2025，**已过期**） | 免征，每辆免税额 ≤ 3 万元 |

认定时点看**《机动车销售统一发票》开具日期**。

> ⚠️ 常见错误：用 2025 年的"免征"口径计算 2026 年的落地价，会把预算低估约 5%。

### 2026 年汽车以旧换新补贴

依据《2026 年汽车以旧换新补贴实施细则》（商务部等 8 部门，商办消费函 2025 年第 467 号，2026-01-01 起执行）：

| 类型 | 买新能源 | 买 2.0L 及以下燃油 |
|---|---|---|
| **报废更新** | 按新车售价 **12%**，最高 **2 万** | 按新车售价 **10%**，最高 **1.5 万** |
| **置换更新** | 按新车售价 **8%**，最高 **1.5 万** | 按新车售价 **6%**，最高 **1.3 万** |

**前置条件（缺一不可）**
- 旧车须于 **2025-01-08 前**登记在申请人名下
- 报废旧车范围：2013-06-30 前注册的汽油乘用车；2015-06-30 前注册的柴油及其他燃料乘用车；2019-12-31 前注册的新能源乘用车
- 所有票据与登记日期须在 **2026-01-01 之后**
- **每人只能享受一次**（报废更新或置换更新二选一）
- 《机动车销售统一发票》与《机动车登记证书》须在**同一省级地区**开具/办理

**申请入口**：全国汽车流通信息管理系统网站 / "汽车以旧换新"小程序

## 三、二手车的三项附加成本（最常被漏算）

1. **牌照额度**：上海、北京等地需新增机动车额度，**可能与车价同量级**。必须提醒用户自行查询当月额度价格后再定总预算。
2. **整备预算**：8 年车龄建议预留 **1–2 万元**（四条轮胎、大保养、刹车片、油液）。
3. **过户费与服务费**：向当地交易市场开票窗口询价，不要凭印象估算。

## 四、排放与限迁核验（易致交易失败的前置条件）

- 京津冀、长三角、珠三角等重点区域执行更严格的迁入标准，据第三方平台整理，**长三角、珠三角已只允许国六 b 车辆迁入**；国五车异地迁入需先确认迁入地是否接受。**此类口径必须引导用户向迁入地车管所/生态环境部门确认**，不要作为结论。
- **平台标注的「欧5/欧6」是欧洲排放标准，不等于中国的「国五/国六」环保信息公开等级**。必须按 VIN 到机动车环保网查询该车实际公开等级后，才能判断能否上牌/迁入。
- 已上牌的国五二手车通常允许**同城过户**（需满足当地条件），这与异地迁入是两回事——报告中要区分清楚。

## 五、写作红线

- 所有金额若为估算，必须显式标注 `[估算]` 并写明假设。
- 残值率 = 现价 ÷ 当年指导价，是判断报价是否偏离行情的最快基准。
- 不允许出现无来源的电话号码、价格、公里数、事故结论。
- 报告结尾必须声明：本报告不构成购车决策建议。

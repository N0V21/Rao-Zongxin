### [AB 实验效果评估 · 首页推荐位改版](./ab-testing-analysis)
> 一次完整实验分析：事前功效分析 → 双指标假设检验 → 分层一致性 → 新奇效应 → 上线建议

用两比例 z 检验与 Welch t 检验评估改版效果，**发现整体显著其实由单一平台拉动**（Android +2.13pp 显著，iOS 实际上无变化），并识别出提升随时间衰减的新奇效应，最终给出"仅在 Android 端放量 + 延长观察"的建议，而不是简单全量。
`Python` `pandas` `scipy` `假设检验` `A/B Test`

### [电商用户行为分析 · 漏斗 / 留存 / RFM](./ecommerce-user-analysis)
> 35,565 条行为日志、12,000 名用户的端到端分析

定位到支付环节是最大流失点（加购用户中 49.6% 未支付），用 cohort 方法算次日 / 3 日 / 7 日留存，用 RFM 把用户切成 5 层并算出各层人均消费，最后验证价值集中度（Top 20% 用户贡献 42.9% GMV）。
`Python` `pandas` `漏斗分析` `留存分析` `RFM`
